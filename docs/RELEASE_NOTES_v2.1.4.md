# MarksVault v2.1.4

v2.1.4 是跨浏览器书签显示、AI 分类反馈和恢复安全补丁版本。

## 主要更新

- 修复 Chrome、Edge 和 Firefox 在轻量书签 API 返回无 `children` 的文件夹节点时被误判为分隔线的问题。文件夹现在可以正常显示、进入，书签可以正常打开。
- 改进 AI 分类提示词：同时提供域名、URL 路径、标题和文件夹路径证据；“其他”只用于证据不足或冲突的书签，不再把不熟悉的域名直接归入“其他”。
- 修复 AI 任务完成后任务页面状态不更新的问题。后台任务与预览计划通过 `planId` 关联，并显示应用中、已完成和已撤销状态。
- AI 分类创建的文件夹记录父目录和原始名称。恢复/撤销仅删除仍为空、未移动、未重命名且由同一计划创建的文件夹，不删除普通用户新增内容。

## Firefox 验证

- Firefox MV2 生产构建通过。
- Manifest 权限与稳定 Gecko ID 校验通过。
- Service Worker 无 DOM 依赖检查通过。
- 当前 Windows 环境未安装 Firefox 可执行程序，因此未进行真实 Firefox 窗口交互测试；GitHub Actions 发布流程会继续执行 `web-ext lint`。

## 安全与隐私

- 测试只使用合成书签、模拟浏览器 API 和假配置。
- 发布包不包含 API Key、GitHub Token 或真实书签数据。
