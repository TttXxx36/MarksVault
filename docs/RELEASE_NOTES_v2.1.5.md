# MarksVault v2.1.5

v2.1.5 是 AI 分类可靠性和任务控制维护版本，针对大批量任务中响应格式异常、长时间等待和错误后无法重新开始的问题进行补强。

## 主要更新

- 为截断输出、流式响应、供应商包装、reasoning-only 响应和多 JSON 增加结构化错误码及可行动提示；诊断摘要只包含脱敏元数据。
- AI 分类提示词默认只要求必要的 assignment 字段，限制可选说明长度；在安全预算内对可恢复的格式/大小错误自适应拆分批次，父批次标记为 `split`，进度和失败数按叶子批次统计。
- 新增“取消本次任务”操作。取消会中止当前请求、持久化终态并清理闹钟；不会自动执行书签写入。取消或失败后可继续已完成检查点，或新建任务并使用修改后的 AI 配置。
- 修复取消请求与后台任务刚启动时的竞态，避免取消后闹钟再次唤醒旧任务。
- 保留 v2.0.1/v2.1.x 的预览、快照、恢复、Firefox 和 Service Worker 安全约束。

## 验证

- Jest：23 个测试套件通过，195 个测试通过，1 个跳过。
- TypeScript 类型检查、ESLint、Chrome/Firefox/Edge 生产构建、manifest 校验和三端无 DOM Service Worker 检查通过。
- Firefox `web-ext lint`：0 errors、0 notices；生成代码存在 2 个既有 `innerHTML` 警告，不影响构建。

- 测试仅使用合成书签、模拟浏览器 API、模拟响应和假配置。
