# MarksVault v2.1.2

v2.1.2 聚焦 AI 分类在慢接口和较大书签集合下的可控性、可观察性与恢复体验。

## 主要更新

- 单次 AI 请求默认超时 30 秒，单批默认总预算 90 秒，最多尝试 2 次；旧版隐含的 60 秒/20 条配置会安全迁移到新默认值。
- 默认批次大小调整为 10。超时、批次预算耗尽或服务端返回内容过大时，大批次会在同一批次预算内自适应拆分，避免一次请求携带过多书签。
- 修正后台进度中的实际尝试次数，并在 Popup 与任务页面每秒读取 IndexedDB 检查点，显示当前批次、尝试次数和耗时。
- 新增 100 条合成书签本地性能基准，以及可选的 1/20/100 条合成书签真实接口烟测。

## 安全与隐私

- 真实接口烟测只发送合成书签，不读取浏览器真实书签，不调用书签写入 API。
- API Key 只能通过本机进程环境变量提供；测试输出不包含地址、请求体、响应体或密钥。
- 发布包不包含测试密钥、真实书签、GitHub Token 或快照内容。
