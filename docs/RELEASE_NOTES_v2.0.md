# v2.0.0 — 用户自配置 AI 智能分类

本版本在 v1.6.0 的跨浏览器基础上增加 AI 分类能力。 Firefox 产物使用 Manifest V3（最低 Firefox 128），以支持用户自定义 AI origin 的运行时权限。AI 服务由用户自行选择和配置，MarksVault 不代管 API Key，也不默认调用任何远程 AI 服务。

## 功能

- 支持填写 API 地址、API Key、Responses API / Chat Completions / 自定义兼容协议和模型。
- 支持测试 API 连通性与读取模型列表。
- API Key 与公开配置分开保存；配置导出和 GitHub 配置备份不会包含 Key。
- 分类前先读取书签标题、URL、域名和文件夹路径，生成只读预览。
- 确认后才创建分类文件夹并移动书签。
- 执行前保存原始书签位置；失败会尝试逆序回滚，最近一次成功操作支持撤销。
- 自定义 API 地址只在测试或分类时申请对应 origin 的可选权限。
- 不配置 AI 时，原有书签、GitHub 备份、任务和 Firefox 功能保持可用。

## 限制

- 第一版分类只创建平面文件夹，不删除书签、不修改 URL、不删除用户原有文件夹。
- AI 返回必须能解析为 JSON；无效响应会终止本批次，不猜测执行。
- 不建议将真实用户书签发送到不可信服务；界面会显示数据范围和目标服务责任。
