# AI 分类任务由后台分批驱动

状态：accepted。AI 分类不再由 Popup 持有完整执行 Promise，而由后台按批次驱动并持久化检查点；这样关闭 Popup、切换标签页或 Service Worker 重启都不会丢失已完成批次。浏览器重启后的任务只标记为可恢复，必须由用户明确继续，以避免在无感知情况下重新发送书签数据或消耗 API 配额。

考虑过的方案：让 Popup 保持打开、关闭 Popup 即暂停、允许多个并行任务。最终选择单个后台任务、批次边界取消和可恢复草稿，因为它同时满足用户体验、书签写入互斥和外部 API 隐私边界。

补充决策：用户可以在任务运行中明确取消当前 AI 分类。取消会中止当前请求、保留已经落盘的批次草稿、清除后台唤醒闹钟，并阻止后续批次自动发送；用户可以选择继续未完成任务，或在修改配置后显式新建分类任务。取消和重新开始都不会直接写入书签。
